## ✨ 功能特性

- 🚀 实时TCP封包监控与截取
- 🔍 精确封包内容查找与过滤
- ✏️ 字节级封包修改功能
- 🛡️ 完善的内存安全机制
- 💻 支持x86/x64应用程序
- ⚡ 低资源占用，长期稳定运行

## 📦 快速开始

### 系统要求
- Windows 7/10/11 (x86/x64)
- Visual Studio 2019 运行库

### 安装方式
1. 下载最新版本: [Releases](https://github.com/tearhacker/lxpackettool/releases)
2. 解压到任意目录_软件根目录哦
3. 运行 `LxPacketTool.exe`

### 从源码构建
```bash
git clone https://github.com/tearhacker/lxpackettool.git
cd lxpackettool
# 使用Visual Studio 2019打开LxPacketTool.sln
# 选择x86或x64配置后构建
